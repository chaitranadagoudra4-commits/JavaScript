1. Variable--It is container used to store value.

2. Three Keywords: 
        1.var
        2.let
        3.const

3. syntax to create variable using var:
     var variableName = value;
     EX: var age = 25;

4. syntax to create variable using let:
     let variableName = value;
     EX: let marks = 98;

5. syntax to create variable using const:
     const variableName = value;
     EX: const c = 30;

6. declaration: creating a variable.
     EX: let age; //here age is declared

7. initialization: giving a variable its first value.
     EX: let age = 25; //here 25 is the intial value 

8. reassignment: changing the value of an existing variables.
     EX: let age = 25;
         age = 30; //here 25 is changed to 30

9. redeclaration: declaring the same variable again
     EX: var a = 10;
         var a = 20;

10. var keyword allows redeclaration

11. var and let both keywords allows reassignment

12. const keyword requires initialization when declared
